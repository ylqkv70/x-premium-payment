## 为什么支付宝直接付不了

X 的订阅走的是国际信用卡通道，结算时它只认境外发行的 Visa / Mastercard。国内的双币信用卡经常因为发卡行风控被拒，支付宝和微信则根本没有接入 X 的结账体系。

绕开这个限制的思路也就两种：要么给自己弄一张 X 认的国际卡，要么让别人替你完成订阅。前者是虚拟信用卡的路子，后者就是所谓的代充。下面按推荐程度排。

## 绑卡失败，按这个顺序排查

绑卡被拒是这一路最常遇到的问题，好在原因就那么几个：

- **余额不够。** 有些地区要加税，充值时多留一点。
- **卡段被拒。** 部分虚拟卡卡段会被 X 的风控直接拒绝，换一个卡段或联系发卡平台换卡。
- **网络环境。** IP 与账号常用地区冲突、线路不干净，是失败的大头。用与账单地区一致的节点重试。
- **账单地址不对。** 地址要和发卡平台要求一致，别随手编一个。
- **浏览器问题。** 换浏览器或清缓存后再试。

> 大部分绑卡失败是网络和卡段的问题，不是卡“坏了”。换环境重试一次，往往就过了。

## 订阅成功之后，这几件事要知道

**蓝标不是秒出的。** 官方规则是：订阅 Premium 或 Premium+ 后账号会自动进入审核，可能需要几个工作日。蓝标要求账号有显示名称、头像和已验证的手机号。另外，改头像、改显示名或改 @用户名，都会触发重新审核，蓝标会暂时消失——这不是被回收了，等审核通过就会回来。

**手机号必须验证。** 所有订阅者在注册时都要确认手机号，这是硬性要求。

**编辑帖文有 1 小时窗口。** 发出去的帖子在一小时内可以有限次修改，改错别字、补链接都靠这个，过期就不能改了。

**不想续费要提前取消。** 订阅默认自动续费，取消需要在续费前至少 24 小时，到 Premium 管理页操作。取消后当前周期的权益还能用到结束。

**退款政策偏严格。** 除法律要求外，订阅一般不予退款，包括账号被封或某些功能暂时不可用的情况。网页版升级更高档位时，剩余价值会抵扣到新套餐；降级则不退当前周期。

**Premium+ 的“无广告”有个小字。** 官方说法是大部分区域无广告，包括 For You、Following 时间线、回复和个人主页，但偶尔仍可能遇到推广内容。

## 常见问题

**只要蓝标，选 Premium 还是 Premium+？**

只要蓝标和基础功能，$8/月的 Premium 够了。Premium+ 多出来的是完全无广告、最高回复权重、Radar、X Pro 和明显更大的 Grok 额度——为这些付五倍价钱，值不值取决于你刷 X 和用 Grok 的强度。

**订了 Premium+，Grok 就随便用吗？**

Grok 的基础功能免费就能用，但有额度限制；Premium 有增强额度，Premium+ 更高。注意 SuperGrok 是和 X Premium 相互独立的另一条产品线，分开计费——如果你把 Grok 当生产力工具每天重度使用，经常触顶的话，可能需要在会员之外单独加订 SuperGrok。
